# Helios

Helios is a lightweight macOS menu bar app for switching a supported external monitor between HDMI 1 and DisplayPort. Features include a Control–Option–H shortcut, keyboard and mouse controls, Return to confirm keyboard selections, immediate switching or a saved 5- or 10-second delay, a visual countdown, and automatic dismissal after inactivity. Run it with `swift run Helios window`; it requires macOS 13 or later, Swift 6.2 or later, and exactly one external monitor set as the main display.
