# Helios

Helios is a lightweight macOS menu bar app for switching a supported external monitor between HDMI 1 and DisplayPort. Features include a Control–Option–H shortcut, keyboard and mouse controls, Return to confirm keyboard selections, immediate switching or a saved 5- or 10-second delay, a visual countdown, and automatic dismissal after inactivity. [Build and install it once](INSTALLATION.md) with `python3 scripts/install-app.py`, then open Helios from your Applications folder; development runs can use `swift run Helios window`. Building requires an Apple Silicon Mac, Swift 6.2 or later, and Python 3; running requires macOS 13 or later and exactly one supported external monitor set as the main display.
